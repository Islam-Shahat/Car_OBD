# Feature folders land phase by phase.

- connection — COM-port discovery, ELM327 handshake, car selection
- scan — DTC read (stored/pending), readiness monitors, safe clear flow
- vehicles — make / model / year picker and vehicle seed data
- dtc — code decoding, Arabic/English explanations
- livedata — live PID streams and charts
- history — saved scan sessions and pre-purchase inspection timeline
- reports — PDF report builder
- settings — language, theme, adapter preferences
